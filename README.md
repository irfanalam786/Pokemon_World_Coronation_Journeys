# Pokémon Anime RPG (SSS Project)

## Phase 1 - Core Engine

This project is a Pokémon Anime-style RPG built using:

- Python (Pygame for frontend)
- JSON (data backend)

## Features (Phase 1 Start)

- Modular architecture
- JSON-based data system
- Scalable engine design

## Run

pip install -r requirements.txt  
python main.py
